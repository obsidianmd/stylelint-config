# stylelint-config-obsidianmd

A Stylelint configuration for Obsidian theme development.

## Installation

You'll first need to install [Stylelint](https://stylelint.io/):

```sh
npm i stylelint --save-dev
```

Next, install `stylelint-config-obsidianmd`:

```sh
npm install stylelint-config-obsidianmd --save-dev
```

## Usage

Add it to your `.stylelintrc.json`:

```json
{
	"extends": "stylelint-config-obsidianmd"
}
```

This is an early, minimal starting point. Rules will be added as the config develops.
